# PaperRead 사용법

PaperRead는 로컬 서비스와 브라우저로 사용합니다. 아래 Bash 명령은 프로젝트 폴더에서 Windows의 Git Bash 또는 macOS의 터미널(zsh/bash)로 실행합니다. macOS는 코드에 실행 경로와 자료 경로가 있지만, 실제 Mac에서의 로그인·번역·PDF 표시는 아직 검증하지 않았습니다.

## 처음 한 번 설치

Node.js 24 이상과 공식 Codex CLI가 설치되어 있어야 합니다. 프로젝트 폴더에서 의존성을 설치합니다.

```bash
npm ci
```

공식 Codex CLI 설치 방법은 [OpenAI 문서](https://learn.chatgpt.com/docs/codex/cli)를 참고하세요. `codex --version`으로 CLI가 실행 경로에 등록되어 있는지 확인합니다. 로그인은 아래의 PaperRead 계정 메뉴에서 진행합니다.

## 실행

화면 파일을 빌드한 뒤 서비스를 시작합니다.

```bash
npm run build
PAPERREAD_INDEX=./dist/client/index.html node --import tsx src/server/main.ts
```

터미널에 `service.ready`와 `http://127.0.0.1:7327`이 표시되면 브라우저에서 <http://127.0.0.1:7327>을 엽니다. 서비스를 종료하려면 실행 중인 터미널에서 `Ctrl+C`를 누릅니다.

코드를 바꾼 뒤 다시 실행할 때는 `npm run build`부터 실행합니다. 서버 명령에 환경 변수를 함께 적었으므로 새 터미널에서도 그대로 사용할 수 있습니다.

Windows PowerShell에서는 다음 명령으로 실행합니다.

```powershell
npm run build
$env:PAPERREAD_INDEX = (Resolve-Path ./dist/client/index.html).Path
node --import tsx ./src/server/main.ts
```

macOS의 기본 자료 경로는 `~/.local/share/paperread`입니다. `XDG_DATA_HOME`이 있으면 그 경로 아래 `paperread`를 사용하며, 자료 폴더 아래 `.codex-home`에는 앱 전용 Codex 인증이 저장됩니다.

## 논문 읽기

1. 화면 오른쪽 위 계정 메뉴에서 **Codex로 로그인**을 누르고 공식 로그인 페이지에서 로그인합니다. 앱 전용 로그인은 PaperRead 화면에서 진행합니다. 터미널에서 `codex login`을 실행할 필요가 없습니다.
2. 첫 화면의 입력란에 공개 PDF URL, 논문 소개 페이지 URL 또는 arXiv 주소·번호(예: `1706.03762`)를 넣고 **논문 열기**를 누릅니다. 내 PC의 파일을 열려면 **PDF 첨부**를 눌러 PDF를 선택합니다.
3. 번역을 시작하려면 화면의 **번역 시작** 버튼을 누릅니다. 논문을 여는 것만으로 번역 요청이 전송되지는 않습니다. 앞쪽 두 쪽을 함께 번역해 첫 화면을 더 빨리 볼 수 있고, 끝난 쪽부터 한국어 지면이 나타납니다. 아직 번역이 끝나지 않은 쪽은 한국어 쪽에 원문 지면이 대신 보입니다.
4. 원문과 한국어를 좌우로 읽습니다. 저장된 논문은 **보관함**에서 다시 열 수 있고, 논문에 관해 묻고 싶으면 **질문하기**를 누릅니다.

저장된 번역을 처음부터 다시 만들려면 **새로 번역**을 누르고 확인창에서 승인합니다. 기존 번역은 영구적으로 삭제되고, 한국어 쪽에 남긴 하이라이트·메모·필기도 모두 삭제됩니다. 원본 PDF와 원문 쪽의 하이라이트·메모·필기는 그대로 남습니다.

화면은 Microsoft Edge의 PDF 보기와 비슷한 모양입니다. 도구 막대에서 켜 둔 도구는 아래에 파란 줄이 표시됩니다.

### 원문 인식

줄 끝에서 하이픈으로 나뉜 영어 단어는 한 단어로 이어 읽고 번역합니다. state-of-the-art처럼 원래 하이픈이 들어가는 단어는 그대로 둡니다.

부록의 예시처럼 번역하지 않고 원문 모양 그대로 보여 주는 줄이 단이나 쪽을 넘어가면, 한 덩어리로 묶어 시작하는 쪽의 한국어 지면에 보여 줍니다.

이전에 저장한 논문은 처음 열 때 저장된 PDF에서 문단을 다시 인식합니다. 이때 네트워크 요청은 보내지 않습니다. 원문이 같은 문단은 저장된 번역을 그대로 쓰고, 바뀐 문단이 있으면 "문단 인식이 바뀌어 새로 번역할 문단이 있습니다"라고 알립니다. 그 문단은 **이어 번역**을 누를 때만 번역합니다.

### PDF URL로 열기

예를 들어 `https://aclanthology.org/2020.acl-main.550.pdf`를 입력합니다. 주소에 `.pdf` 확장자가 없어도 실제 응답이 PDF이면 사용할 수 있습니다. NeurIPS·PMLR처럼 공개 PDF 링크가 있는 논문 소개 페이지도 받을 수 있습니다. PDF 링크가 여러 개이거나 페이지에서 찾지 못하면 사이트의 PDF 버튼에서 직접 주소를 복사해 입력하세요.

URL은 로그인 없이 공개된 HTTPS PDF만 받습니다. 파일 첨부와 URL 모두 PDF 크기는 50 MiB, 쪽 수는 300쪽까지입니다. 로그인·유료 접근을 대신 처리하지 않습니다. 스캔 PDF의 글자 인식(OCR)은 지원하지 않습니다.

arXiv 버전과 외부 PDF는 별도 자료입니다. 같은 외부 URL의 PDF 내용이 바뀌면 기존 번역을 유지하면서 새 자료로 저장하므로 버전별 번역이 섞이지 않습니다. 입력창에서 URL을 다시 열면 현재 PDF를 확인하고, **보관함**에서 다시 열면 저장한 버전을 네트워크 요청 없이 읽습니다.

### 내 PC의 PDF 첨부

화면 위의 **PDF 첨부**를 누르고 파일을 선택하면 PDF를 검사하고 원문을 추출한 뒤 읽기 화면을 엽니다. 첨부한 원본과 번역은 보관함에 저장됩니다. 파일 이름을 바꿔도 내용이 같으면 기존 논문과 번역을 재사용하며, 내용이 달라지면 별도 논문으로 저장합니다. 손상되었거나 제한을 넘는 PDF는 오류 메시지를 표시합니다.

파일을 첨부하는 것만으로 번역이나 질문을 요청하지는 않습니다. 논문 내용은 번역 시작이나 질문 전송을 직접 누를 때 Codex CLI를 거쳐 OpenAI로 전송됩니다.

## 번역과 질문에 쓸 모델

계정 메뉴의 **기본 모델**에서 새 번역과 질문에 쓸 모델을 고르고 **저장**을 누릅니다. 읽기 화면의 **번역 모델**이나 질문 패널에서 모델을 바꿔도 같은 기본 모델로 저장됩니다. **목록 새로고침**을 누르면 쓸 수 있는 모델 목록을 다시 확인합니다. 로그인할 때도 목록을 다시 확인합니다.

저장한 모델을 더 쓸 수 없으면 "기본 모델을 쓸 수 없어 공식 기본 모델을 씁니다"라는 안내와 함께 지금 쓰는 모델을 보여 줍니다. 목록에는 그 모델이 "현재 사용 불가"로 표시됩니다.

이미 시작한 번역은 처음 고른 모델로 이어서 번역하며, 그 모델은 논문 제목 아래에 표시됩니다. 그 모델을 쓸 수 없게 되면 번역이 멈추고 "선택한 모델을 쓸 수 없습니다"라고 알립니다. 질문 대화도 시작할 때의 모델을 계속 씁니다. 대화 도중에 모델을 바꾸면 "선택한 모델은 다음 새 대화부터 적용됩니다"라고 알립니다.

## 표시하고 메모하기

읽기 화면 위쪽 도구 막대의 도구는 원문과 한국어 양쪽에서 씁니다.

- **선택**(`V`)으로 글자를 끌어 선택하면 메뉴가 열립니다. **하이라이트** 옆의 색을 누르면 그 색으로 칠하고, **메모 달기**를 누르면 메모 카드가 열립니다. **질문에 인용**은 선택한 문장을 질문 입력란에 넣고, **복사**는 클립보드에 복사합니다.
- **형광펜**(`H`)은 칠할 줄을 끌면 바로 저장됩니다. 옆의 ▾를 눌러 색 4가지 중 하나를 고르고 두께를 조절합니다.
- **펜**(`P`)으로 자유롭게 필기하며, 그린 필기는 자동으로 저장됩니다. 옆의 ▾에서 색 4가지와 두께를 고릅니다.
- **지우개**(`E`)는 닿는 필기선을 지웁니다. 크기는 작게, 보통, 크게 중에서 고르고, **지운 필기 되돌리기**로 지운 필기를 되살릴 수 있습니다. 하이라이트와 메모는 지우개로 지워지지 않습니다.

`Esc`를 누르면 선택 도구로 돌아갑니다.

메모를 단 하이라이트에는 작은 메모 표시가 붙고, 누르면 메모 카드가 열립니다. 카드 위쪽의 메모 메뉴에서 **편집**, **메모 삭제**, **하이라이트 삭제**, **질문에 인용**을 고르고 색을 바꿉니다.

### 메모 모음

도구 막대 오른쪽의 **메모 모음**을 누르면 논문 전체의 하이라이트와 메모가 쪽 순서로 모입니다. 같은 쪽에서는 원문 기록이 한국어 기록보다 앞에 옵니다. 검색창에서 선택한 글과 메모를 찾고, **전체**, **원문**, **한국어**로 목록을 걸러 볼 수 있습니다.

항목을 누르면 그 쪽으로 이동하고 해당 기록을 잠시 강조합니다. 항목 아래의 **삭제**로 목록에서 바로 지우고, **메모 추가 · 색상** 또는 **메모 편집 · 색상**으로 메모 카드를 엽니다.

번역문이나 쪽 배치가 바뀌어 원래 자리에 표시할 수 없는 기록은 목록 아래 **위치를 잃은 기록**에 따로 모입니다. 이 기록은 지우기 전까지 보관됩니다.

## 원문과 한국어에서 찾기

읽기 화면에서 `Ctrl+F`(macOS는 `Cmd+F`)를 누르면 찾기 창이 열립니다. 찾을 말을 입력하면 원문과 한국어를 함께 찾고, 양쪽에서 찾은 개수를 따로 보여 줍니다. `Enter`는 다음 결과, `Shift+Enter`는 이전 결과로 이동하고, `Esc`는 찾기 창을 닫습니다.

한국어 쪽은 번역이 끝난 문단만 찾습니다. 한국어 쪽에 원문 지면이 대신 보이는 쪽은 원문에서만 찾습니다.

## 접속 상태 확인

서비스가 실행 중일 때 Git Bash의 새 창에서 다음 명령으로 연결 상태를 확인할 수 있습니다.

```bash
curl http://127.0.0.1:7327/api/connection
```

기본 포트는 `7327`입니다. 다른 포트를 쓰려면 실행 명령에 `PAPERREAD_PORT`를 추가합니다.

```bash
PAPERREAD_PORT=7330 PAPERREAD_INDEX=./dist/client/index.html node --import tsx src/server/main.ts
```

그 경우 브라우저 주소도 `http://127.0.0.1:7330`으로 바꿉니다.
