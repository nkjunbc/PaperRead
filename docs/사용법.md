# PaperRead 사용법

PaperRead는 로컬 서비스와 브라우저로 사용합니다. 아래 Bash 명령은 프로젝트 폴더에서 Windows의 Git Bash 또는 macOS의 터미널(zsh/bash)로 실행합니다. macOS는 코드에 실행 경로와 자료 경로가 있지만, 실제 Mac에서의 로그인·번역·PDF 표시는 아직 검증하지 않았습니다.

## 처음 한 번 설치

Node.js 24 이상과 공식 Codex CLI가 설치되어 있어야 합니다. 프로젝트 폴더에서 의존성을 설치합니다.

```bash
npm ci
```

공식 Codex CLI 설치 방법은 [OpenAI 문서](https://learn.chatgpt.com/docs/codex/cli)를 참고하세요. `codex --version`으로 CLI가 실행 경로에 등록되어 있는지 확인합니다. 로그인은 아래의 PaperRead 계정 메뉴에서 진행합니다.

## 실행

화면 파일을 빌드한 뒤 서비스를 시작합니다.

```bash
npm run build
PAPERREAD_INDEX="$(pwd)/dist/client/index.html" node --import tsx src/server/main.ts
```

터미널에 `service.ready`와 `http://127.0.0.1:7327`이 표시되면 브라우저에서 <http://127.0.0.1:7327>을 엽니다. 서비스를 종료하려면 실행 중인 터미널에서 `Ctrl+C`를 누릅니다.

코드를 바꾼 뒤 다시 실행할 때는 `npm run build`부터 실행합니다. 서버 명령에 환경 변수를 함께 적었으므로 새 터미널에서도 그대로 사용할 수 있습니다.

Windows PowerShell에서는 다음 명령으로 실행합니다.

```powershell
npm run build
$env:PAPERREAD_INDEX = (Resolve-Path ./dist/client/index.html).Path
node --import tsx ./src/server/main.ts
```

macOS의 기본 자료 경로는 `~/.local/share/paperread`입니다. `XDG_DATA_HOME`이 있으면 그 경로 아래 `paperread`를 사용하며, 자료 폴더 아래 `.codex-home`에는 앱 전용 Codex 인증이 저장됩니다(`src/server/main.ts:21`, `src/server/codex/runtime.ts:53`).

## 논문 읽기

1. 화면 오른쪽 위 계정 메뉴에서 **Codex로 로그인**을 누르고 공식 로그인 페이지에서 로그인합니다. 앱 전용 로그인은 PaperRead 화면에서 진행합니다. 터미널에서 `codex login`을 실행할 필요가 없습니다.
2. 첫 화면의 입력란에 arXiv 번호(예: `1706.03762`) 또는 arXiv 주소를 넣고 **논문 열기**를 누릅니다.
3. 번역을 시작하려면 화면의 번역 시작 버튼을 누릅니다. 논문을 여는 것만으로 번역 요청이 전송되지는 않습니다.
4. 원문과 한국어를 좌우로 읽습니다. 저장된 논문은 **보관함**에서 다시 열 수 있고, 논문에 관해 묻고 싶으면 **질문하기**를 누릅니다.

저장된 번역을 처음부터 다시 만들려면 **새로 번역**을 누르고 확인창에서 승인합니다. 이 동작은 현재 번역을 지우고 새 작업을 시작합니다.

## 접속 상태 확인

서비스가 실행 중일 때 Git Bash의 새 창에서 다음 명령으로 연결 상태를 확인할 수 있습니다.

```bash
curl http://127.0.0.1:7327/api/connection
```

기본 포트는 `7327`입니다. 다른 포트를 쓰려면 실행 명령에 `PAPERREAD_PORT`를 추가합니다.

```bash
PAPERREAD_PORT=7330 PAPERREAD_INDEX="$(pwd)/dist/client/index.html" node --import tsx src/server/main.ts
```

그 경우 브라우저 주소도 `http://127.0.0.1:7330`으로 바꿉니다.
